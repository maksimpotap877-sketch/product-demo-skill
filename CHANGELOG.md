# Изменения

## 0.4.0

- Переписан Skill: монтажный лист, диагностика по таймкодам, отбор исходников, короткая проверка сложного фрагмента перед длинным экспортом.
- Устойчивое кадрирование с сохранением пропорций; общая модель камеры для cinematic/classic; статичная камера и прямые склейки по умолчанию.
- Последний кадр видео удерживается без подмены сторонним снимком; реальные размеры проверяются отдельно для каждого источника.
- Явная привязка источников и событий, проверки ключевых кадров и скорости камеры. Автоматическое заполнение длительности пустыми паузами удалено.
- `type` действительно вводит символы последовательно; обновлён ключ кеша записи.
- Команда `review` сохраняет проверку содержания, кадрирования, движения и звука с хешем конкретного MP4. Технически готовый файл остаётся кандидатом до редакционной проверки.
- Неподтверждённые native144, просмотр и прослушивание не становятся passed из-за успешного экспорта.

## 0.3.0

- Обязательный разбор исходников перед записью и рендером: продукт, сценарий, запуск, признак успеха, диапазоны строк и хеши.
- Блокировка черновиков и устаревших свидетельств; документированное исключение для явного URL-only запроса.
- Ограничение неудачных и оборванных попыток стадий.
- Переносимый Skill для Codex, Claude Code либо обоих клиентов с общим runtime.
- Учебный init копирует сайт в новый проект для изучения кода на месте.
- Русские инструкции Codex/Claude/GLM, Remotion Skills/MCP, установки и рабочего процесса.
- Пример готового видео и воспроизводимые исходники в одном репозитории.

## 0.2.0

- Нейросетевая русская речь Svetlana/Dmitry с явным разрешением на внешний сервис.
- Композиции Remotion, камера, измеренные источники и кеш.
- Проверка во втором проекте, повторный монтаж без повторной записи.

## 0.1.0

- Браузерная запись, план, речь, локальный рендер, QA и первая версия Skill.
