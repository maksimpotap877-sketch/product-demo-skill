# Инструкции для Claude Code

Прочитайте [README.md](README.md), [Skill](skills/product-demo/SKILL.md) и [рабочий процесс](docs/WORKFLOW_RU.md). Подключение Claude Code и GLM/Z.AI: [clients.md](docs/clients.md). Установка: [INSTALL_RU.md](docs/INSTALL_RU.md).

Порядок работы: прочитать инструкции и релевантный код продукта, понять задачу пользователя, обосновать запуск, связать действия и результат с исходниками, заполнить demo.understanding.json, проверить сценарий в браузере без записи, затем capture → narrate → plan → render → inspect. Черновик, устаревшие хеши и отсутствие признака успеха блокируют работу.

Не заменяйте чтение исходников случайным кликаньем. Не обходите лимит неудач новыми каталогами. Правки речи и монтажа выполняйте по сохранённым источникам. Если кода действительно нет и дан только URL, используйте документированное исключение url-only с наблюдениями интерфейса и причиной отсутствия кода.

При разработке toolkit изучите соответствующие модули src/, выполните npm run typecheck, npm test, npm run build. Собранная установка должна работать из другого проекта без папки разработки.

Вход передавайте пользователю в видимом окне без записи. Ключи не запрашивайте в чате. Внешний TTS требует разрешения на отправку текста. Частота источника не равна частоте рендера. QA без просмотра/прослушивания отмечайте not-tested. Установка Skill не доказывает E2E внутри Claude/GLM.

Версия 0.4: до рендера составьте монтажный лист и отберите явные источники/диапазоны; проверьте короткий сложный фрагмент. Камера неподвижна по умолчанию, кадр сохраняет пропорции, переходы не должны удваивать интерфейс. Технический inspect не одобряет монтаж. Сохраните отдельную проверку конкретного MP4 через review; без полного обычного просмотра/прослушивания соответствующие критерии остаются not-tested. См. [docs/EDITING_RU.md](docs/EDITING_RU.md).
