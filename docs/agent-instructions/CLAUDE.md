# Product Demo: инструкции для проекта

Это шаблон для дополнения существующего `CLAUDE.md`, а не команда его перезаписать.

При создании или изменении демо используйте установленный `/product-demo` и его локальный launcher. Сначала прочитайте текущие инструкции проекта и релевантный исходный код. Разберите назначение продукта, аудиторию, маршрут, обработчики действий, изменение состояния и видимый результат. Не заменяйте изучение кода осмотром папок или догадкой по названию framework.

Составьте и проверьте `demo.understanding.json` по актуальному контракту установленного `analyze --help`. Привяжите сценарий к прочитанным файлам/строкам и хешам. Пустой draft не является подтверждением понимания. Если доступен только URL, явно укажите этот режим и ограничьте утверждения наблюдаемым интерфейсом.

Перед записью проверьте UI без записи и без изменений бизнес-данных. Авторизацию выполняет пользователь в отдельном видимом браузере при выключенных записи, скриншотах, трассировке и логировании содержимого полей. Секреты не запрашиваются в чате и не попадают в конфигурацию, Git или видео.

Показывайте только реально работающие действия и результаты. Используйте демоданные. Не отправляйте приглашения, не публикуйте, не покупайте и не меняйте production-данные без соответствующего запроса. Для онлайн-озвучки учитывайте уже данное разрешение на передачу текста; не подменяйте выбранный голос молча.

Переиспользуйте подходящую запись. Изменение текста, камеры или титров требует только затронутых этапов. После неудачи сначала установите причину; ограничьте исправление одной проблемы двумя целевыми циклами. Если она не устранена, сохраните материалы и сообщите точную причину и следующий шаг. Не сбрасывайте журнал неудач новым каталогом или бессмысленным изменением параметров.

Разделяйте native capture fps, fps исходного файла и fps рендера. Технические проверки, просмотр кадров, плавность при воспроизведении и субъективное прослушивание оцениваются отдельно. Не называйте непроверенное проверенным.

Выбор GLM вместо другой модели не меняет эти правила. Навык и доступ к инструментам определяются клиентом агента. Не меняйте провайдера, платный тариф или ключи как побочный эффект работы над демо.
