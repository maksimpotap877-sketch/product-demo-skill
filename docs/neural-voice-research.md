# Выбор бесплатной русской нейросетевой озвучки

Проверка 22 сентября 2026. Цель — заменить системный SAPI женским нейросетевым голосом, получить настоящее аудио без платного API и сохранить работающий переносимый workflow. Сравнительного прослушивания всех моделей не проводилось; здесь зафиксирован практический выбор и его ограничения.

| Вариант | Фактическая проверка | Решение |
|---|---|---|
| Microsoft Edge / SvetlanaNeural через `edge-tts` 7.2.8 | Живой каталог, настоящий синтез, MP3 24000 Hz / 48 kbit/s, полный decode, кеш и повторный монтаж | Выбран для текущего публичного демо; женский голос, скорость 0%, без API-ключа и оплаты |
| Microsoft Edge / DmitryNeural | Каталог и настоящий мужской синтез в integration test | Доступен как явный мужской выбор |
| Microsoft Azure / DariyaNeural | Указана в документации Azure, отсутствует в проверенном каталоге Edge | Не предлагается как работающий Edge-голос |
| Silero `v5_5_ru` | Прочитана документация, синтез не запускался | Основные русские модели имеют NC-ограничения, поэтому не выбраны общим default для коммерческих product demo |
| Silero `v5_cis_base` / `_nostress` | Прочитаны описание и `LICENSE_CIS`, модели не скачивались | MIT-вариант с поддержкой русского через префикс `ru_`; документация требует явных ударений. Перспективный офлайн-кандидат, качество здесь не проверено |
| Piper | Исследованы официальный проект и требования к лицензиям отдельных голосов | Лицензии моделей различаются; конкретный нейросетевой русский голос здесь не установлен и не прослушан |
| Windows SAPI / Irina | Реальный WAV 22050 Hz из первоначального демо | Оставлен явным офлайн-вариантом; пользователь оценил голос как слишком роботизированный |

Источники: [Microsoft language and voice support](https://learn.microsoft.com/en-us/azure/cognitive-services/speech-service/language-support), [upstream edge-tts](https://github.com/rany2/edge-tts), [PyPI 7.2.8](https://pypi.org/project/edge-tts/7.2.8/), [Silero models](https://github.com/snakers4/silero-models), [Silero CIS license](https://github.com/snakers4/silero-models/blob/master/LICENSE_CIS), [Piper](https://github.com/OHF-Voice/piper1-gpl), [Piper voice licenses](https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/VOICES.md).

## Что именно проверено

Неизменённый опубликованный `edge-tts` установлен в отдельное пользовательское Python-окружение. Использованы его публичные `list_voices` и `Communicate`; TLS, authentication и код клиента не изменялись. Ключи, платная подписка, вход в аккаунт и клонирование голоса не понадобились. Цена проверенных запросов — 0 USD; долгосрочная доступность и безлимитный тариф не заявляются.

Живой каталог вернул только два русских ID: `ru-RU-SvetlanaNeural` и `ru-RU-DmitryNeural`. Проверенные женские пробы 0% и −3% — один голос с разным темпом, не два диктора. Пробы полностью декодированы, имеют реальные длительности 14.664 и 15.120 секунды и ненулевую амплитуду. Женский и мужской голоса, повторное использование кеша и изменение одной реплики проверены отдельным сетевым integration test. Один временный `NoAudioReceived` наблюдался при исследовании: предусмотрена одна ограниченная повторная попытка; отсутствие результата завершает операцию ошибкой без замены на SAPI.

Нельзя вывести естественность из частоты дискретизации, названия Neural, waveform или отсутствия ошибок декодера. Субъективное прослушивание агентом и рейтинг качества между этими моделями остаются `not-tested`. Окончательную оценку выбранного голоса пользователь может дать по реальным пробам и новому видео.
