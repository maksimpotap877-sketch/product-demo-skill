Дата подготовки версии 0.3.0: 23 сентября 2026. Основная проверенная среда: Windows, Node.js 24, FFmpeg 8.1.1, Edge, Remotion 4.0.527. Зависимости закреплены lockfile.

- Исходные браузерные клипы: около 25 fps; снимки интерфейса: 2560×1440.
- Женский голос: ru-RU-SvetlanaNeural, скорость 0%, реальный синтез через edge-tts.
- SHA-256: `cd82b4a6416131b050a73581a68ff363fa1addc62334e814ddaf61aa04f21575`.
- Итоговый статус: `degraded` из-за неподтверждённого native capture 144 fps.
- Технические проверки пройдены. Агент просмотрел декодированные кадры; просмотр движения и субъективное прослушивание агентом не заявлены.

[Перенесённый отчёт QA без локального пути пользователя](../assets/demo-qa.json), [кадры](../assets/demo-contact-sheet.png). Конфигурация принятого монтажа находится в `examples/basic-web/cinematic.config.ts`; после новой записи абсолютные точки резки нужно сверить с измеренными событиями, поскольку время исполнения браузера может отличаться.

## Изменения 0.3.0

`npm test`: 64 теста, 63 passed, 1 opt-in сетевой тест пропущен. TypeScript и сборка прошли. Реальный сетевой синтез при этом отдельно выполнен в полном запуске ниже; пропущенный тест не выдаётся за выполненный.

Установленный Skill 0.3.0 запущен из отдельного проекта «Форма», вне исходной папки toolkit. Код сервера и страницы прочитан, составлен содержательный разбор, проверена готовность интерфейса без записи. Отсутствующий и черновой разбор действительно остановили capture до появления его результатов. После валидации выполнены реальная запись многошагового сценария, новый синтез Svetlana, Remotion и технический QA: 6 секунд, 1280×720, 60 fps; частота источника около 25 fps, итог `degraded`. Короткий файл проверки прилагается к релизу отдельно от принятого основного ролика.

Обязательный разбор проверяется до записи и рендера, включая прямые вызовы этих модулей. Тесты проверяют отсутствие/черновик/устаревание разбора, диапазоны исходников, изменение сценария, исключение URL-only, запрет небезопасных путей и ограничение неудачных попыток. Структурная проверка прямо возвращает `semanticUnderstandingVerified: false`: качество понимания и сценария остаётся обязанностью агента.

Установка предусматривает Codex и Claude Code с одним независимым runtime. Тесты проверяют отдельные каталоги клиентов, сохранение чужих файлов и резервных копий, launcher из папки с пробелами и кириллицей. Совместимость формата и запуск самого модельного клиента — разные проверки.

## Границы подтверждения

| Возможность | Статус |
|---|---|
| Реальный сайт → capture → русский нейросетевой голос → Remotion → MP4 → технический QA на Windows | Проверено в 0.2.0 и 0.3.0 |
| Skill из другого проекта | Проверено в 0.2.0 и 0.3.0 |
| Обновление камеры без записи/синтеза | Проверено в 0.2.0 |
| Код и сценарий как обязательный вход, защита от устаревших свидетельств | Автоматические проверки 0.3.0 |
| Перенаправленные каталоги Windows MSIX и форматы npm 11/12 | Исправлены по обнаруженным случаям, покрыты проверками |
| Remotion MCP: handshake и запрос документации | Проверено ранее в Codex; сервер deprecated |
| Native capture 144 новых состояний/секунду | Не достигнуто; benchmark degraded |
| Render 144 fps | Выполнен отдельно в предыдущем запуске; это не native capture |
| Claude Code и GLM: полная работа модели от запроса до видео | Не проверено, инструкции основаны на официальной документации |
| macOS/Linux, любой произвольный сайт, сторонний вход | Не проверено |

Новый запуск должен сохранять собственный отчёт. Нельзя переносить отметку passed от другого файла, другого запуска, другого голоса или другой версии клиента без проверки.
