# Russian voice and timing

Read the installed `voices --help`, `voices preview --help` and `narrate --help`. The preferred provider is `edge-neural`: Russian neural speech from Microsoft Edge online speech through the pinned, unmodified `edge-tts` client. `auto` selects this provider after authorization. It does not silently fall back to Windows speech. `windows-sapi` is an explicit older offline option, useful only when that voice is requested or accepted.

Neural synthesis sends the final `spokenText` to Microsoft, with no footage, screenshots, project files or credentials. Explain this before first use, check the conversation for existing authorization, and use `--allow-external-tts` only within that authorization. Do not ask again when the user has already approved this destination and text scope. If authorization is absent, finish the script, capture and edit work while requesting the missing decision; do not mislabel a silent provider substitution as completion. Supplied local audio is also supported.

For an authorized neural preview use `voices preview --tts-provider edge-neural --allow-external-tts --voice female --output <absolute-path>`. For a captured run use `narrate --run <absolute-path> --tts-provider edge-neural --allow-external-tts --voice female --speech-rate 0`. Full pipeline config uses `ttsProvider: "edge-neural"`, `allowExternalTts: true` and `speechRatePercent: 0`; these declarations record authorization rather than granting it. The first requested neural preview or narration installs the pinned Python environment under application data when needed, without administrator rights. A new host still needs working Python and network access.

The verified Russian neural IDs are `ru-RU-SvetlanaNeural` and `ru-RU-DmitryNeural`; always confirm the live catalog or its fresh cache before use. Do not invent a more attractive sounding voice name. Preview the actual chosen voice on the same natural Russian sentence, with modest rate changes only when useful. A technically decoded file does not establish natural pronunciation, expressive pacing or pleasant listening.

Use `--language ru-RU --voice female` or `--voice male` and preserve the requested perceived voice gender. A saved choice takes precedence over the female fallback when no choice is supplied. Use `--no-save-voice-preference` for synthetic acceptance tests so a test voice does not change the user's preference. A pitch-shifted version of one file is not a second voice. Do not substitute another gender if the requested voice is unavailable. Select `--voice-id` only from the checked catalog. Preview male and female voices on the same short Russian text before claiming both work; distinguish synthesis/decoding success from subjective listening.

For supplied audio use `--narration-file <absolute WAV or MP3>` with the narration command. Confirm its actual measured duration and ownership/permission. Original voice and segment files are retained for revisions.

Write natural short Russian sentences based on observed UI outcomes. Normalize pronunciation of numbers, brand names, abbreviations and «ё». Do not rush long copy to fit a fixed scene. Prefer a shorter sentence or longer scene; keep the voice consistent between segments.

Timings come from measured segment durations unless a provider exposes verified alignment. Segment subtitles are valid; equally divided word timings are not word alignment. Preserve this limitation in the manifest/report. Reuse cached segments for unchanged text, model, voice and pronunciation settings; changing one phrase should only regenerate that segment.

The tested Edge service required no API key and incurred no metered API charge. It is a consumer service accessed through a third-party client: availability, an exact remote model version and commercial publication rights are not guaranteed by the toolkit. Preserve these facts in the manifest. For a paid provider, state the provider, exact outgoing text, estimate and spending limit before the first charge. A key or paid chat subscription is not consent to API charges. Secrets must enter a hidden local prompt or credential store, never CLI arguments, tracked config, preview or chat. Check current official provider terms before publication. A documentation link alone is not an implemented provider.
